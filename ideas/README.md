# Ideas

Raw possibilities not yet being built. The "someday maybe" list.

## Purpose

Capture possibilities before they become projects:
- Product ideas
- Business concepts
- Features to consider
- Experiments to try

## Idea vs Project

| Idea | Project |
|------|---------|
| No one working on it | Someone actively building |
| "Wouldn't it be cool if..." | "We're building X by date Y" |
| Exploration mode | Execution mode |

## When Ideas Become Projects

An idea graduates to a project when:
- Someone is assigned to build it
- There's a timeline
- Resources are allocated
- Specs are being written

## Page Structure

Simple markdown, no strict template:

```markdown
# Idea Name

What if... [the core idea]

## Why This Might Work
- Reason 1
- Reason 2

## Concerns
- Concern 1
- Concern 2

## Next Steps If We Pursue
- [ ] Step 1
- [ ] Step 2

## Related
- [[projects/related-project]]
- [[concepts/related-concept]]
```

## Keep It Light

Ideas are cheap. Don't over-document. Save the rigor for projects.

---

Ideas are seeds. Not all will grow. That's okay.

# Inbox Directory

Quick captures that haven't been filed yet.

## What goes here

- Notes you haven't categorized
- Voice memos transcribed but not processed
- Quick ideas that need more context

## What does NOT go here

- Anything with a clear category → file directly

## Lifecycle

1. Capture in inbox/
2. Process within 24-48 hours
3. Move to correct directory
4. Delete from inbox/

If something stays in inbox/ for more than a week, it's a signal the schema needs to evolve.

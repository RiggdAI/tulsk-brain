# Concepts

Mental models, frameworks, and reusable thinking tools.

## Purpose

Store distilled knowledge that helps you think better:
- Mental models
- Frameworks
- Principles
- Mental shortcuts

## What Goes Here

| Type | Example |
|------|---------|
| Mental models | First principles thinking, Inversion |
| Frameworks | Jobs-to-be-Done, OKRs |
| Principles | "Strong opinions, loosely held" |
| Heuristics | Decision-making shortcuts |

## Concept vs Idea

- **Concept**: Could you *teach* it? Is it a thinking tool?
- **Idea**: Could you *build* it? Is it a project possibility?

## Page Structure

```markdown
# Concept Name

> One-paragraph definition.

## The Core Idea
What it is, in simple terms.

## Why It Matters
Why this concept is useful.

## How To Apply It
Practical applications.

## Related Concepts
- [[concepts/related-concept-1]]
- [[concepts/related-concept-2]]
```

# Archive

Dead pages and historical record. Content that is no longer active but worth preserving.

## Purpose

Store pages that:
- Are no longer relevant but shouldn't be deleted
- Have historical value
- Might be referenced later

## Naming Convention

Same as source directory. For example:
- `archive/people/old-contact.md`
- `archive/companies/defunct-startup.md`

## When to Archive

- Project completed or cancelled
- Person no longer in your network
- Company shut down or pivoted
- Idea abandoned

## Archive vs Delete

**Archive** when:
- Content has historical value
- Might be referenced in future
- Was significant at some point

**Delete** when:
- Clearly wrong information
- No value whatsoever
- Privacy concern

---

Archived pages are part of your brain's memory. They inform future decisions.

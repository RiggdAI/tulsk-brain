# Prompts

Reusable LLM prompts and prompt templates.

## Purpose

Store prompts you use frequently:
- Agent instructions
- Analysis prompts
- Writing prompts
- Utility prompts

## What Goes Here

| Type | Examples |
|------|----------|
| Agent instructions | Role definitions, behavior configs |
| Analysis | Summarization, extraction, evaluation |
| Writing | Drafting, editing, formatting |
| Utility | Formatting, conversion, parsing |

## Prompt Structure

```markdown
# Prompt Name

## Purpose
What this prompt does.

## Variables
- `{variable_1}`: Description
- `{variable_2}`: Description

## Prompt

```
[The actual prompt text]

Use {variable_1} to...
Consider {variable_2} when...
```

## Usage Example
```
[Example of how to use it]
```

## Notes
- Tip 1
- Tip 2
```

## Example Prompts

- `summarize-meeting.md` - Extract key points from meeting notes
- `analyze-person.md` - Generate person page from conversation
- `weekly-review.md` - Generate weekly review summary

---

Prompts are your conversation templates with AI. Reuse and refine.

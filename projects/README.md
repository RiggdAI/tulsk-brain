# Projects

Active work with specs. Things being built right now.

## Purpose

Track projects currently in progress:
- Product development
- Research initiatives
- Internal tools
- Client work

## Project vs Idea

| Project | Idea |
|---------|------|
| Someone is building it | No one working on it |
| Has timeline | No timeline |
| Has owner | No owner |
| In execution mode | In exploration mode |

## What Goes Here

| Type | Examples |
|------|----------|
| Products | Mobile app, API, feature |
| Research | Study, analysis, investigation |
| Internal | Infra, tooling, process improvement |
| Client | Consulting, contracts |

# Programs

Major life workstreams and enduring commitments. The long game.

## Purpose

Track long-term programs you're committed to:
- Career development
- Health and fitness
- Learning journeys
- Relationship building
- Life projects

## Program vs Project

| Program | Project |
|---------|---------|
| Ongoing, no end date | Time-bounded |
| "Stay healthy" | "Run a marathon" |
| "Be a better leader" | "Complete leadership course" |
| Enduring commitment | Specific deliverable |

## What Goes Here

| Type | Examples |
|------|----------|
| Health | Fitness routine, diet, wellness |
| Career | Skills to develop, roles to explore |
| Learning | Languages, instruments, subjects |
| Relationships | Family, friends, network |
| Finance | Savings, investments, wealth building |

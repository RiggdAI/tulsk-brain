# Deals

Financial transactions with terms and decisions. Investments, acquisitions, partnerships.

## Purpose

Track deals you're evaluating, negotiating, or have completed:
- Investment opportunities
- Acquisition discussions
- Partnership agreements
- Major contracts

## Deal Lifecycle

| Stage | Description |
|-------|-------------|
| Exploring | Initial interest, gathering info |
| Due Diligence | Deep dive, verifying claims |
| Negotiating | Working on terms |
| Closed | Deal completed |
| Passed | Decided not to proceed |

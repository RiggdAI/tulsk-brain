# Personal

Private notes and reflections. Not for sharing.

## Purpose

Store personal, sensitive, or private content:
- Journal entries
- Personal reflections
- Private thoughts
- Sensitive information

## What Goes Here

| Type | Examples |
|------|----------|
| Journaling | Daily reflections, gratitude |
| Private assessments | Honest opinions you can't share publicly |
| Personal goals | Life objectives, not work |
| Sensitive info | Passwords (encrypted), private keys |

## Privacy Note

This directory should typically be:
- In `.gitignore` if pushed to a public repo
- Encrypted if stored in cloud
- Never shared without explicit permission

## No Template Needed

Personal pages are freeform. Write whatever you need.

```markdown
# 2026-05-20

Personal reflection...

Today I learned...
I'm grateful for...
Tomorrow I want to...
```

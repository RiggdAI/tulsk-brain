# Slack Manifest Reference

Generated by `hermes slack manifest --write`.

## Manifest Structure

The manifest declares:
- **49 slash commands** - All Hermes commands as native Slack commands
- **14 OAuth scopes** - Permissions for reading messages, files, and posting
- **6 event subscriptions** - Real-time message delivery
- **Socket Mode** - WebSocket connection (no public endpoint needed)

## Key Sections

### Display Information

```json
"display_information": {
  "name": "Hermes",
  "description": "Your Hermes agent on Slack",
  "background_color": "#1a1a2e"
}
```

### App Home (Messages Tab)

```json
"features": {
  "app_home": {
    "home_tab_enabled": false,
    "messages_tab_enabled": true,
    "messages_tab_read_only_enabled": false
  }
}
```

**Critical**: `messages_tab_enabled: true` is required for DMs to work. Without it, users see "Sending messages to this app has been turned off".

### OAuth Scopes

```json
"oauth_config": {
  "scopes": {
    "bot": [
      "app_mentions:read",
      "assistant:write",
      "channels:history",
      "channels:read",
      "chat:write",
      "commands",
      "files:read",
      "files:write",
      "groups:history",
      "groups:read",
      "im:history",
      "im:read",
      "im:write",
      "users:read"
    ]
  }
}
```

**Most commonly missed**:
- `channels:history` - Bot can't read public channel messages
- `groups:history` - Bot can't read private channel messages
- `files:read` - Bot can't see images/voice attachments

### Event Subscriptions

```json
"settings": {
  "event_subscriptions": {
    "bot_events": [
      "app_mention",
      "assistant_thread_context_changed",
      "assistant_thread_started",
      "message.channels",
      "message.groups",
      "message.im"
    ]
  },
  "socket_mode_enabled": true
}
```

**Critical**: Without `message.channels` and `message.groups`, Slack never delivers channel messages to the bot.

## Full Manifest

See `slack-manifest.json` in your profile directory after running:

```bash
hermes slack manifest --write
```

## Installation

```bash
# Install Hermes via uv
uv tool install hermes-agent --python 3.11

# Verify
hermes --version

# Generate manifest
hermes slack manifest --write
```

## Tokens Location

| Token | Variable | Location |
|-------|----------|----------|
| Bot Token | `SLACK_BOT_TOKEN` | `{profile}/.env` |
| App Token | `SLACK_APP_TOKEN` | `{profile}/.env` |
| Allowed Users | `SLACK_ALLOWED_USERS` | `{profile}/config.yaml` |

## Deprecated: hermes-slack-bot repo

**Note**: The `hermes-slack-bot` repo (https://github.com/WeiYee93/hermes-slack-bot) was created before discovering Hermes has built-in Slack gateway support. It's now deprecated in favor of the official `hermes gateway` approach.

Do not create custom slack-bolt bots unless you have a specific need not covered by the native gateway.
